# Raster Pick to Light

Raster Pick to Light is an embedded pharmacy shelf-location system. It uses
addressable RGB LEDs to guide staff to the correct medication location.

## Repository status

This public repository has been initialized with the full product specification.
Firmware, hardware-integration code, tests, and release artifacts will be added
according to that specification.

## Documentation

- [Product specification](docs/PRODUCT_SPECIFICATION.md)

## Intended scope

- Embedded C firmware and hardware drivers
- W5500 Ethernet connectivity and pharmacy JSON integration
- Ten WS2812 LED channels
- Embedded web dashboard and OTA firmware updates
- Persistent configuration, automated testing, and release artifacts
